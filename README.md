# NetworkShow-2
Десктопное приложение для мониторинга сетевого трафика в реальном времени на Windows. Захватывает пакеты с выбранного интерфейса, агрегирует их по соединениям, процессам и удалённым хостам, и подсвечивает подозрительную активность.

Написано на C# / .NET 8 / WPF (MVVM) с использованием SharpPcap и PacketDotNet.

## Возможности

- Захват пакетов в режиме реального времени через Npcap
- Определение процесса (PID + имя) по каждому соединению через `GetExtendedTcpTable` / `GetExtendedUdpTable`
- Обратный DNS и извлечение TLS SNI для классификации соединений
- Распознавание сервиса по hostname (Teams, GitHub, Telegram, Discord, Steam, Cloudflare и т.д.)
- Таблица соединений с группировкой (по процессу / хосту / протоколу / зоне) и фильтрацией (IP, диапазон IP, процесс, протокол, поиск по строке)
- Топ удалённых IP и топ процессов по объёму трафика
- График входящей и исходящей скорости (LiveCharts2)
- Уведомления:
  - первое соединение с новым внешним IP
  - подключение к подозрительному порту (Telnet, SMB, RDP, VNC, IRC и т.п.)
  - резкий рост трафика относительно скользящего среднего
  - соединение с IP из чёрного списка
- Чёрный и белый списки IP
- Логирование трафика в JSON / CSV с ротацией по размеру и экспортом снимков соединений
- Тёмная и светлая темы, переключаются на лету

## Стек

- .NET 8, WPF
- [SharpPcap](https://github.com/dotpcap/sharppcap) — захват пакетов
- [PacketDotNet](https://github.com/dotpcap/packetnet) — парсинг
- [LiveChartsCore](https://livecharts.dev/) — графики
- [CommunityToolkit.Mvvm](https://learn.microsoft.com/dotnet/communitytoolkit/mvvm/) — MVVM source generators

## Требования

- Windows 10 / 11
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) для сборки
- [Npcap](https://npcap.com/) (установить с опцией WinPcap-compatible mode)
- Запуск **от имени администратора** — захват пакетов требует прав

## Использование

1. Запустить приложение от имени администратора.
2. Выбрать сетевой интерфейс из выпадающего списка.
3. Нажать **Старт**.
4. Использовать вкладки и фильтры для анализа трафика.
5. Включить **Лог в файл**, чтобы записывать пакеты в JSON / CSV (в подпапку `logs/` рядом с exe).

## Ограничения

- Только Windows (зависит от Npcap и `iphlpapi.dll`).
- Требуются права администратора.
- Сопоставление пакета с процессом неточно для UDP и для очень короткоживущих TCP-сокетов.
- Не предназначен для линейной скорости 10 GbE — рассчитан на десктопный трафик.
